# Little Redline

A collector-first Hot Wheels storefront prototype built with plain HTML, CSS, and JavaScript.

## Run it

Open `index.html` in a browser, or serve this folder with any static web server. No build step or package installation is needed.

## Current scope

- Responsive landing page and product catalog
- Category filters and product search
- Shopping bag saved in browser local storage
- Illustrative product listings and vector car artwork

The eight listings and prices are examples for the prototype, not confirmed stock. Checkout is intentionally a placeholder. Before taking orders, replace the sample catalog with the real inventory and connect secure server-side order handling, a payment gateway, shipping, and store policies.
